# Add to Calendar

A simple Svelte app for creating `.ics` calendar files in the browser.

[Open the app](https://opsmon.github.io/calendar/)

## Features

- Event title, date, time, description, location, links, organizer, and reminder.
- Live event preview.
- Regular and all-day events.
- RU/EN interface.
- Purple light and dark themes.

## Run Locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The static build is generated in `dist/`.
